# Phase 260818-l22 Plan 01: FOTF Sticky-Top Nav Summary

Converted the Fate of the Fellowship companion's main tab menu (Setup/Turn/Dice/Rules) from a `position:fixed` bar pinned to the viewport bottom (which overlapped the Nocturne site footer) into a `position:sticky;top:0` bar that pins to the top of the scroll flow — mirroring the Burning Banners companion's sticky-top header pattern.

## What Changed

All four edits confined to `src/components/armory/FateOfTheFellowship.tsx`:

1. **`.ff .nav` CSS** (was `/* ---- bottom nav ---- */`, now `/* ---- top nav ---- */`): changed from `position:fixed;left:0;right:0;bottom:0` with `border-top` and `padding-bottom:env(safe-area-inset-bottom)` to `position:sticky;top:0;z-index:30` with `margin:0 -16px;padding:0 16px` (matching the status bar's edge-flush treatment) and `border-bottom` instead of `border-top`. The `env(safe-area-inset-bottom)` padding was dropped entirely since it only made sense for a bottom-pinned bar. `z-index:30` retained so nav paints above the `z-index:20` status bar.

2. **`.ff .body` bottom padding**: reduced from `108px` (reserved space for the old fixed bottom bar) to `24px` (a normal small gap, since the nav no longer floats over content).

3. **`.ff .status` sticky offset**: changed `top:0` to `top:58px` so the status bar stacks directly beneath the now-sticky-top nav instead of both bars fighting for `top:0`.

4. **JSX reorder**: moved the entire `<nav className="nav">...</nav>` block from after `.body`'s closing tag (as a sibling, last child of `.ff`) to be the FIRST child inside `<div className="body">`, immediately before `<div className="status">`. This is required because a `position:sticky` element only sticks relative to its own position in normal document flow — it had to precede the content it stays above. Deleted the old trailing `<nav>`; there is exactly one `<nav className="nav">` in the file now, and it renders before `.status`.

No behavior changes to the tabs (`NAV.map`, `ICONS`, `setTab`, `aria-current` all untouched — pure CSS + positional JSX move). No new dependencies. The `.nb`, `.nb.on`, and `.nb svg` rules were left untouched.
