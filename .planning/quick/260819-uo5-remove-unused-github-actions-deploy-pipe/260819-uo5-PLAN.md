# Quick Task 260819-uo5: Remove the unused GitHub Actions deploy pipeline

## Problem

`.github/workflows/deploy.yml` is a `workflow_dispatch`-only deploy pipeline. The
owner never uses the manual "Publish"/"Run workflow" run and deploys exclusively
via local `npm run deploy`. Nothing triggers it — the admin app has no
`repository_dispatch` sender (it only shows a "Last published" timestamp and states
edits go live immediately). It is dead code, and several docs still present it as a
deploy option, which is misleading.

## Tasks

1. **Delete the workflow.** Remove `.github/workflows/deploy.yml` (the only workflow).
   - done: file gone; `npm run deploy` (local) remains the sole deploy path.

2. **Update docs that present GitHub Actions as a deploy/publish mechanism.** Keep the
   local `npm run deploy` path and the analytics env-var docs; only remove the
   GitHub-Actions-as-deploy references.
   - `README.md` — "How it works" publish line (21); "Build & deploy" GitHub Actions
     paragraph (53–55); Configuration "GitHub Actions secrets/vars" aside (60).
   - `LAUNCH.md` — §4 GH Actions deploy bullet (30–33); §6 analytics var/redeploy (45);
     §7 Publish-test-via-workflow step (54); "Ongoing: how to publish" (58–59); the
     "Already done" GH-Actions-deploy mention (68).
   - `docs/go-live-v1.1.md` — §1 "deploy options (local or GitHub Actions Deploy workflow)" (28–29).
   - `docs/environment.md` — "GitHub Actions secrets/vars for deploys" framing (5, 26).
   - `.claude/CLAUDE.md` — Commands "Publishing … via the GitHub Actions Deploy workflow" (24);
     Dev-tools table GitHub Actions row present-tense CI/deploy claim (104).
   - out of scope: the "Alternatives Considered" / "Sources" research rows (82, 127, 165)
     are historical rationale, not operational claims — leave them.

3. **Verify** `npm run build` still passes.

## Notes

Firebase Hosting config, `.firebaserc`, and `npm run deploy`/`deploy:rules` are
untouched. The build-time Firestore read (`FIREBASE_SERVICE_ACCOUNT`) still applies to
local deploys, so its env docs stay — only the "as GitHub Actions secrets" framing changes.
